<h1 align="center">GMStash</h1>
<h3 align="center">A "simple" stash manager.</h3>


### Basic setup
- Create a script in GameMaker
	- Copy everything from [GMStash.gml](https://codeberg.org/maklore/GMStash/src/branch/main/GMStash.gml)
	- Paste to script file

- Create your first stash.
  - ```gml
      GMStash.create("inventory", 10);
    ```
- Use the dot notation like above to use the other methods.

- Enjoy!
